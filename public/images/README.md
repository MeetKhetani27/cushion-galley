## Image Guidelines:
- Use high-quality images (minimum 800x1000px)
- Use JPG format for best compression
- Keep file sizes under 500KB each
- Use consistent lighting and background
- Show product details clearly

## Gallery Images:
The gallery automatically displays product images, so no separate gallery images are needed.
